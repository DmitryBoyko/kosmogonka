ГОЛОСА ГЕРОЕВ — ЧЕЛОВЕЧЕСКИЕ ЗАПИСИ
Источник: Voices - Essentials, часть Essentials Series.
Автор: NOX SOUND / Nox_Sound_Design.
Страница автора: https://nox-sound-design.itch.io/essentials-series-sfx-nox-sound
Лицензия: CC0 1.0 Universal, коммерческое использование разрешено автором.
https://creativecommons.org/publicdomain/zero/1.0/
Дата получения: 1 ноября 2026 года. Получено через бесплатную загрузку на странице автора, без регистрации и без покупки.
В библиотеке есть две мужские и две женские актёрские партии. Выбраны Male V2 для мальчика и Female V2 для девочки. Это разные взрослые исполнители, не документальные записи детей 8–10 лет. Голоса не клонировались и не синтезировались.

36 разных файлов: для каждого героя по три дубля jump, laugh, joy, win, hit, surprise. Для joy — короткий смех, для laugh/win — разные дубли длинного смеха, для hit — короткая реакция Hit_Short, для surprise — мужские Breath_Shocked и женские Breath_Gasp. Диалоговые файлы и боевые кличи не включались. Отбор бессловесности опирается на категории библиотеки.

Оригиналы: docs/audio_sources/nox/*.wav — исходные 48 кГц/24 бит/моно.
Полное соответствие исходник → игровой файл, SHA-256 каждого оригинала, параметры обработки: docs/audio_sources/manifest.json.
Сохранённая выдержка об условиях автора: docs/audio_sources/author-statement.txt.
Уведомление в сборке: assets/audio/VOICE_LICENSE.txt. CC0 не требует указания авторства; источник указан добровольно. Автор не заявляется участником или рекомендателем игры.

Обработка: ffmpeg, обрезка цифровой тишины по -55 dB, коррекция высоты +3 полутона для мальчика / +1 для девочки с сохранением темпа, RMS к -22 dBFS с ограничением пика -5 dBFS, плавные края 6/12 мс, PCM 24 кГц/16 бит/моно. Нормализация не повышает пики выше ограничения; динамические записи могут быть тише целевого RMS.
Повторная подготовка: python tools/prepare_voices.py. Скрипт сверяет контрольные суммы и использует сохранённые оригиналы; сеть не требуется. Требуется ffmpeg в PATH.
Синтетические boy_*/girl_* полностью заменены. Генератор tools/generate_audio.py теперь создаёт только эффекты и не трогает голоса.

ОГРАНИЧЕНИЕ ПРОВЕРКИ
В данной среде нет доступного аудиопрослушивания. Проверены форматы, длительности, уровень PCM, загрузка Godot и выбор записей игровыми событиями. Нельзя выдавать это за прослушивание или подтверждение детского/весёлого звучания. Художественная оценка и отсутствие неожиданно речевых призвуков ожидают пользователя. Примеры без музыки: build/voice-boy-preview.wav и build/voice-girl-preview.wav; порядок — прыжки, удивление, смех, радость, столкновение, финиш (по одному дублю).

ИГРОВЫЕ ЭФФЕКТЫ
15 оригинальных файлов: star, jump, land, step, slide, hit, click, boost, warning, win, engine, whoosh, honk0/1/2. Созданы tools/generate_audio.py: детерминированный математический синтез PCM 24 кГц/16 бит/моно без внешних моделей или записей.
