# PROVENANCE - Downtown City Kit
All geometry was modelled procedurally by Greanapple Games in Blender 4.2.3 (using an in-house build script). No AI-generated content and no third-party meshes were used.
Textures are CC0 from Poly Haven (https://polyhaven.com/license), 1k JPG, shipped as JPG in textures/ (plus 512 px downscales in textures_512/):
- red_brick_03 -> mat_brick_red (https://polyhaven.com/a/red_brick_03)
- yellow_brick -> mat_brick_yellow (https://polyhaven.com/a/yellow_brick)
- white_sandstone_blocks_02 -> mat_stone (https://polyhaven.com/a/white_sandstone_blocks_02)
- concrete_wall_008 -> mat_concrete (https://polyhaven.com/a/concrete_wall_008)
- concrete_floor_02 -> mat_roof (https://polyhaven.com/a/concrete_floor_02)
- asphalt_02 -> mat_asphalt (https://polyhaven.com/a/asphalt_02)
- concrete_pavement -> mat_pavement (https://polyhaven.com/a/concrete_pavement)
- metal_plate -> mat_metal (https://polyhaven.com/a/metal_plate)
- bark_brown_02 -> mat_bark (https://polyhaven.com/a/bark_brown_02)
- fine_grained_wood -> mat_wood (https://polyhaven.com/a/fine_grained_wood)
- leaves_cluster_diff.png: original, procedurally drawn (PIL) by Greanapple Games.
Preview lighting only (not shipped in the models): Poly Haven CC0 HDRI kloofendal_48d_partly_cloudy_puresky (https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky).
No Blender bundled assets ended up in the final meshes. The Essentials library has no city content, so I built everything from primitives.

AI disclosure: no generative AI was used for any model, texture or image in this pack.
